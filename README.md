# 软件设计师 · 考点精讲与模拟考场

面向「计算机技术与软件专业技术资格（水平）考试 · 软件设计师（中级）」的开源学习与模拟考试网站。
纯前端实现，无需后端，构建产物可直接静态托管，也提供**双击即可打开的单文件版**。

**完全开源免费**，基于 MIT 协议发布，无广告、无付费内容、无需注册。

- 源码：<https://github.com/yutils/ruankao-se-designer>
- 在线体验（GitHub Pages）：<https://yutils.github.io/ruankao-se-designer/>

## 功能

| 模块 | 说明 |
|---|---|
| 知识地图 | 可缩放 / 拖拽 / 展开的思维导图，13 章 → 68 节，选中章节右侧联动详情面板 |
| 考点精讲 | 逐节精讲，标注 ★★★ 必考 / ★★ 高频，含重点框、易错点、记忆口诀、公式与例题 |
| 题库练习 | 447 道题，支持按章节 / 仅真题 / 随机模式，选完即时判定并给解析 |
| 模拟考场 | 全真模拟、章节测评、历年真题卷、错题重做四种模式 |
| 成绩诊断 | 分数环、合格判定、章节得分率排序、逐题解析（错题 / 未答 / 答对筛选） |
| 错题与统计 | 错题本（答对自动移出）、学习进度、成绩趋势图、站内全文搜索 |

**题库构成**：447 题 = 102 道公开真题 + 345 道依据考纲自编的模拟题，全部附解析。

| 真题年份 | 2024下 | 2023下 | 2023上 | 2022下 | 2022上 | 2020下 |
|---|---|---|---|---|---|---|
| 题量 | 28 | 7 | 10 | 4 | 24 | 29 |

全真模拟从 447 题池中**按章节分值权重抽取 75 题**（软工 13、面向对象 11、数据结构 9……），
每次组卷不同，120 分钟倒计时，交卷自动判分（45 分合格）。

## 快速开始

```bash
npm install        # 安装依赖
npm run dev        # 开发模式 → http://localhost:5173（同时监听局域网，可用手机访问）
npm run build      # 构建到 dist/
npm run preview    # 预览构建产物
```

> 路由使用 Hash 模式，`dist/` 可直接放到任意静态服务器（Nginx、GitHub Pages、对象存储）的任意子目录下运行。

### 部署到 GitHub Pages

仓库已内置 Workflow（`.github/workflows/static.yml`）：推送到默认分支即自动
`npm ci` → `npm run test` → `npm run build` → 部署 `dist/`（**不是**直接上传源码目录，
因为 `dist/` 被 gitignore，仓库里没有构建产物）。

在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions** 即可，
首次部署完成后访问 `https://<用户名>.github.io/ruankao-se-designer/`。

### 免安装单文件版

```bash
npm run build:single
```

在项目根目录生成 **`软考软件设计师-考点精讲.html`**（约 2.3 MB，CSS/JS 全部内联）。
**双击即可在浏览器打开使用**，无需 Node、无需服务器，可直接发给同学。

| 命令 | 说明 |

| `npm run dev` | 本地开发（热更新） |

| `npm run e2e` | 浏览器端到端冒烟（自动构建 + 内置静态服务器） |

### 端到端回归（可选）

```bash
node scripts/e2e-full.mjs
```

自带静态服务器（不依赖外部进程），遍历全部路由与 13 个章节页，覆盖非法路由回退、
空成绩 / 空会话访问、搜索特殊字符、连点越界、损坏 localStorage 等边界场景，
输出检查项并统计控制台错误，错误非零时以退出码 1 结束。

## 技术栈

Vue 3（`<script setup>`）+ Vite 6 + Vue Router 4（Hash 模式）+ KaTeX（公式渲染）。
状态用 `reactive` 自建轻量 store，无 Pinia；持久化直接读写 localStorage。
思维导图与成绩趋势图均为手写 SVG，未引入图表库。

## 数据说明

- 考试科目设置、题量、时长、合格线与分值分布依据公开考试安排与近年真题统计整理，
  **分值为参考值**（页面已标注每年略有浮动），不代表任何年份的官方精确数据。
- 真题来自公开流传的版本，**2022 上 / 2022 下 / 2020 下**为历年真题卷整理，
  其余为考生回忆版；题干与选项顺序可能与原卷存在差异。
  抽取时已剔除含图、多空、选项残缺的题目——宁可少收，也不收会误导人的残题。
- 模拟题为依据考纲自编，页面均明确标注「模拟题」，不与真题混淆。
- 学习数据保存在浏览器 localStorage，不会上传。
